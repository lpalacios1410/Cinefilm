## Description

A lightweight movie catalog that lets users browse films in a clean, card-based layout. Built with vanilla HTML, CSS, and JavaScript as a practice project to strengthen frontend fundamentals.

---

## Tech Stack

| Category | Technology |
|---|---|
| **Markup** | HTML5 |
| **Styling** | CSS3 |
| **Logic** | JavaScript (Vanilla) |
| **Deployment** | Vercel |

---

## Features

- Movie catalog with card-based grid layout
- Clean, responsive design
- Lightweight — no framework overhead
- Fast load times

---

## Run Locally

```bash
git clone https://github.com/lpalacios1410/Cinefilm.git
cd Cinefilm
```

Open `index.html` in your browser or use a live server:

```bash
npx serve .
```
